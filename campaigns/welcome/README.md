Leur présence dans ce dépôt ne prouve ni l'envoi, ni la livraison, ni l'activation d'un envoi automatique. Ils ne contiennent aucune liste de destinataires, configuration de fournisseur d'envoi ou donnée d'accès. Aucun service d'envoi n'est lancé par ces fichiers.

Ces exemples ne décrivent pas de bonus chiffré, de quota d'envoi ou de résultats de campagne. Pour préparer un envoi réel, vérifier séparément les informations du produit, les liens, le rendu dans les clients de courrier concernés et les conditions applicables au message.

## English

These are **static public examples** of account welcome messages in French, English, Italian and Arabic. Each language has an HTML and a plain-text version. The Arabic HTML retains its right-to-left layout.

Publishing the files does not establish that messages have been sent or delivered, or that an automated sending flow is active. They include no recipient list, email-provider configuration or access credentials, and do not run a sending service.

Sample recipient names have been replaced by generic greetings. The remote founder-portrait cell has been removed. The founder introduction and signature are retained; the role is stated on the [official About page](https://kom-5a.com/about). Support links point to the [official contact page](https://kom-5a.com/contact).

**Remote image dependency:** the HTML files request only the logo at `https://kom-5a.com/emails/logo_kom5a.png`. Display depends on that resource and the reader's image settings. Its alternative text is `KOM-5A`. An image-enabled preview may contact that server. The examples contain no tracking pixel, script or form.

The files make no claim about a numerical bonus, sending capacity or campaign performance. Before using them for a real message, separately verify current product information, links, email-client rendering and the conditions applicable to that message.
