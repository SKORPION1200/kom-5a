# Security reporting

We welcome responsible reports of security vulnerabilities affecting KOM-5A. **Do not disclose a vulnerability, exploit steps, credentials or personal data in a public GitHub issue or pull request.**

Use this repository's [private vulnerability reporting](https://github.com/SKORPION1200/kom-5a/security/advisories/new) if available. If that channel is unavailable, contact [info@kom-5a.com](mailto:info@kom-5a.com?subject=KOM-5A%20security%20report) and ask for a private reporting channel. Share only the minimum detail needed in the first message.

Please include the affected surface, a concise description, the potential impact and a safe way to reproduce the issue. Avoid accessing other users' accounts or data, changing production state, disrupting the service or running broad automated tests without written authorization.

This public documentation repository does not contain the production application. Reports about the app, website or APIs are still welcome through the private channels above. We will review reports and coordinate next steps; this page does not establish a bug bounty or a response-time commitment.
