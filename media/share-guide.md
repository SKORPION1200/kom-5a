## Lien depuis un site / Link from a website

Pour proposer aux visiteurs un accès à la documentation publique, un lien simple peut être intégré à une page pertinente du site qui présente le projet :

```html
<a href="https://github.com/SKORPION1200/kom-5a">
  Documentation publique KOM-5A sur GitHub
</a>
```

Cet exemple ne modifie aucun site et ne signifie pas que le lien a déjà été intégré. Il ne contient ni script ni collecte de données. La publication sur un site doit suivre le processus de mise à jour de ce site.

This example does not change a website or establish that the link has already been added. It contains no script or data collection. A live website change should follow that website's update process.

## Partage utile / Useful sharing

Partagez un guide là où il répond à une question ou à un besoin réel. Les retours sur la documentation sont bienvenus dans les issues du projet ; les données de compte et les failles doivent rester dans les canaux privés indiqués dans [SECURITY.md](../SECURITY.md).

Share a guide where it answers a real question or need. Keep account data and security reports in the private channels described in [SECURITY.md](../SECURITY.md).

Les compteurs de visites et les interactions GitHub ne démontrent pas une inscription ou une vente. Un lien balisé peut identifier des visites issues de GitHub si l'analytique du site les mesure ; il ne configure pas lui-même cette mesure.
